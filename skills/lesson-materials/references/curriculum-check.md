# 성취기준 확인 절차

1. NCIC 국가교육과정정보센터(https://www.ncic.re.kr)에서 "2022 개정 교육과정" → 학교급 → 교과 교육과정 원문(PDF/HWP)을 연다.
   - 웹 검색 보조: `"2022 개정" <과목> 교육과정 성취기준 <단원 핵심어> site:ncic.re.kr`
2. 해당 영역의 성취기준 목록에서 단원에 맞는 코드와 문장을 찾아 **원문 그대로** 옮긴다. 띄어쓰기·문장부호도 바꾸지 않는다.
3. 코드 형식 예: [6수01-06] (초 5~6학년군 수학, 01영역 6번째). 학년군 숫자: 초1~2 → 2, 초3~4 → 4, 초5~6 → 6, 중 → 9. 고등은 과목별 약칭이 붙는다. 이 규칙은 참고용이며, 최종 근거는 원문이다.
4. 원문을 열지 못했거나 PDF에서 문장을 확인하지 못하면 `[확인 필요]`를 붙이고, 어디까지 확인했는지 안내에 적는다. 교육부·시도교육청 공개 자료에서 문장을 확인했으면 그 자료 이름을 함께 적는다.
5. 함께 확인하면 좋은 것: 해당 성취기준의 "성취기준 해설", "성취기준 적용 시 고려 사항"(오개념·지도 유의점 근거로 활용).
6. 학년·학기 배치는 교과서(출판사)마다 다를 수 있으니, 단원 순서를 단정하지 말고 "교육과정 기준" 또는 "[확인 필요]"로 표시한다.
