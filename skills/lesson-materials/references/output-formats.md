# 결과물 형식 상세

만드는 경로는 `SKILL.md`의 「도구별 경로」를 따른다. 이 문서는 결과물의 내용과 조판이다.

## 1. 구글 슬라이드 (40분 기준 8~12장)

권장 구성(과목에 맞게 조정):

- 슬라이드 1: 표지 — 단원명, 차시, 학습 목표
- 슬라이드 2: 도입 — 생활 장면/질문으로 동기유발 (노트에 도입 멘트)
- 슬라이드 3: 학습 문제 제시
- 슬라이드 4~7: 활동 1·2 (구체물 → 그림 → 기호 순서 등)
- 슬라이드 8: 오개념 짚기 — "~해도 될까?" 형식, 반례와 함께
- 슬라이드 9: 활동지·형성평가 안내
- 슬라이드 10: 정리 — 정리 발문 2~3개, 다음 차시 예고, 하단에 "※ 초안입니다. 수업 전 반드시 검토하세요."

규칙:

- 구성안 단계에서 각 장을 "슬라이드 N: 제목"으로 정하고, 그 제목을 실제 슬라이드 제목으로 쓴다.
- 화면에는 핵심만(한 장 3줄 안팎), 설명은 발표자 노트에.
- 발표자 노트: 교사가 그대로 읽어도 되는 구어체. "여러분, ~ 본 적 있나요?" 식. 예상 학생 반응과 되묻기 발문 포함.
- 글꼴 크기: 제목 32pt 이상, 본문 20pt 이상. 고대비 색.
- 분수 막대·도형·그래프 등은 슬라이드의 도형·표 기능으로 실제로 그린다.
- 브라우저 에이전트는 slides.google.com에서 직접 만든다.
- 코딩 에이전트는 `.pptx`를 만든 뒤, Google Drive 플러그인이 있으면 편집 가능한 구글 슬라이드로 가져온다. 플러그인이 없으면 `.pptx`를 주고 드라이브에 올리면 구글 슬라이드로 열린다고 안내한다.

## 2. 활동지 PDF (A4 세로)

조판 공통: A4, 여백 18mm, 본문 11.5pt, 제목 16~18pt.

- 브라우저: 구글 문서 페이지 설정으로 맞춘 뒤 PDF로 내려받는다. 학생용 다음에 교사용이 오도록 한 문서에서 쪽을 나누거나, 문서를 둘로 나눠도 된다.
- 코딩 에이전트: `assets/a4.css`로 HTML을 조판하고 `scripts/build_pdf.py`로 PDF를 만든다. `활동지.pdf` 한 파일에서 학생용 쪽 다음에 교사용 쪽을 둔다.

학생용(1~2쪽):

- 머리말: 학년/반/번호/이름 칸(빈칸), 단원·차시, 학습 목표 한 줄
- 활동 1~3: 문제만. 풀이 공간(표·빈 상자) 충분히
- 스스로 점검 체크(☐ 이해했어요 / ☐ 조금 헷갈려요) — 점수 없음
- 맨 아래: ※ 초안입니다. 수업 전 반드시 검토하세요.

교사용(새 쪽부터, 머리말에 "교사용"):

- 문항별 정답과 풀이(검산 완료)
- 지도 유의점, 예상 오개념과 대응 발문
- 빨리 끝낸 학생용 추가 과제
- 참고·변형 출처 표기(있으면)
- 맨 아래: ※ 초안입니다. 수업 전 반드시 검토하세요.

## 3. 형성평가 퀴즈 PDF 2개

- 파일 A `퀴즈_문제지.pdf`: 5문항 내외. 선택형·단답형·서술형을 섞는다. 배점·총점 표기 없음.
- 파일 B `퀴즈_정답해설.pdf`: 문항별 정답, 해설, 오답 보기별 예상 오개념(보기 번호와 내용 일치 재확인), 피드백 문장 예시.
- 둘 다 맨 아래: ※ 초안입니다. 수업 전 반드시 검토하세요.
- 만들지 않을 것: 채점 기준표, 점수 구간, 등급, 서열/순위.

## 4. 수업용 AI 프롬프트

예시 틀(단원에 맞게 채운다):

```text
[Gemini Gems — 학생 연습 도우미 지침]
너는 <학년> <과목> '<단원>' 학습을 돕는 도우미야. 정답을 바로 알려 주지 말고, 한 단계씩 질문으로 힌트를 줘. 성취기준 <코드> 범위 안에서만 문제를 내. 학생에게 이름·학교 같은 개인정보를 묻지 마. 틀리면 왜 그렇게 생각했는지 먼저 물어봐.

[NotebookLM — 교사용]
(소스: 교육과정 원문 해당 쪽, 직접 만든 활동지·퀴즈) "이 소스를 바탕으로 <단원>에서 학생들이 자주 보이는 오개념 5가지와 각각을 바로잡는 발문을 정리해 줘. 소스에 없는 내용은 '소스에 없음'이라고 표시해 줘."
```

공통 안내: "학생 실명·성적 등 개인정보는 넣지 마세요."

코딩 에이전트는 이 전문을 `AI_프롬프트.txt`로 저장한다.
