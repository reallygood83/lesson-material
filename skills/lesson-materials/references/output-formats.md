# 결과물 형식 상세

만드는 경로는 `SKILL.md`의 「도구별 경로」를 따른다. 이 문서는 결과물의 내용과 조판이다.

## 1. 구글 슬라이드 (40분 기준 8~12장)

권장 구성(과목에 맞게 조정):

- 슬라이드 1: 표지 — 단원명, 차시, 학습 목표
- 슬라이드 2: 도입 — 생활 장면/질문으로 동기유발 (노트에 도입 멘트)
- 슬라이드 3: 학습 문제 제시
- 슬라이드 4~7: 활동 1·2 (구체물 → 그림 → 기호 순서 등)
- 슬라이드 8: 오개념 짚기 — "~해도 될까?" 형식, 반례와 함께
- 슬라이드 9: 활동지·형성평가 안내
- 슬라이드 10: 정리 — 정리 발문 2~3개, 다음 차시 예고, 하단에 "※ 초안입니다. 수업 전 반드시 검토하세요."

규칙:

- 구성안 단계에서 각 장을 "슬라이드 N: 제목"으로 정하고, 그 제목을 실제 슬라이드 제목으로 쓴다.
- 화면에는 핵심만(한 장 3줄 안팎), 설명은 발표자 노트에.
- 발표자 노트: 교사가 그대로 읽어도 되는 구어체. "여러분, ~ 본 적 있나요?" 식. 예상 학생 반응과 되묻기 발문 포함.
- 글꼴 크기: 제목 32pt 이상, 본문 20pt 이상. 고대비 색.
- 분수 막대·도형·그래프 등은 슬라이드의 도형·표 기능으로 실제로 그린다.
- 브라우저 에이전트는 slides.google.com에서 직접 만든다.
- 코딩 에이전트는 `.pptx`를 만든 뒤, Google Drive 플러그인이 있으면 편집 가능한 구글 슬라이드로 가져온다. 플러그인이 없으면 `.pptx`를 주고 드라이브에 올리면 구글 슬라이드로 열린다고 안내한다.

## 2. 활동지 PDF (A4 세로)

상세 제작·검수는 `pdf-layout.md`, 정밀 조판 스타일은 `../assets/exam-print.css`를 따른다. A4 세로, 여백 15~20mm 안팎, 본문 11~12pt(기본 11.4pt), 명조 계열 본문·고딕 제목, 얇은 선과 절제된 회색을 쓴다. 저학년은 더 큰 글씨와 1단을 우선한다.

- Aside는 HTML 정밀 조판을 브라우저에서 PDF로 출력한다. 편집용 Google Docs는 필요 시 별도로 제공하고, PDF와 조판이 다르면 구분한다.
- 코딩 에이전트는 같은 CSS를 연결하고 `scripts/build_pdf.py`로 PDF를 만든다. 단순 자동 흐름용 `assets/a4.css`와 고정 쪽 `.sheet` CSS를 섞지 않는다.
- `활동지.pdf`에서 학생용을 먼저, 교사용을 새 쪽부터 둔다. 교사용이 학생용 바로 뒷면에 인쇄되지 않도록 인쇄 범위를 안내한다. 쪽수는 글씨를 줄여 맞추지 않는다.

학생용(보통 1~2쪽, 필요 시 증가):

- 머리말: 단원·차시, 학생용 표시, 학년·반/번호/이름의 빈칸, 학습 목표 한 줄.
- 활동 번호는 01, 02처럼 뚜렷하게 구분한다. 긴 지문·설명은 문항과 간격을 둔다.
- 그림 그리기에는 약한 점 격자 또는 빈 공간, 계산·분해에는 무선 풀이 공간, 식·검산에는 전용 기입 칸, 설명에는 7~8mm 간격 답안선을 둔다.
- 나란히 비교할 대상만 2칸으로 배치한다. 모든 활동을 일괄 2단으로 만들지 않는다.
- 스스로 점검 또는 "오늘의 한 문장"을 두되 점수는 넣지 않는다.
- 문제만 표시하고 정답·완성된 풀이를 학생용에 노출하지 않는다.

교사용(머리말에 "교사용"):

- 필요하면 "수업 운영 가이드"와 "활동 정답과 지도 메모"로 나누어 2쪽 이상으로 만든다.
- 수업 운영: 성취기준 원문·출처, 차시 총시간과 일치하는 단계별 시간, 활동 및 대응 발문. 슬라이드의 순서·시간과 맞춘다.
- 정답: 문항별 풀이·검산, 예상 오개념과 지도 유의점, 빠른 학생용 추가 과제. 설명에 도움이 되는 분해나무·도형은 실제 그림으로 넣는다.

매 쪽 하단: "※ 초안입니다. 수업 전 반드시 검토하세요.", 현재/전체 쪽수, 학생용·교사용 구분. 본문과 겹치지 않도록 별도 영역에 둔다.

## 3. 형성평가 퀴즈 PDF 2개

### A. `퀴즈_문제지.pdf`

- 5문항 내외, 선택형·단답형·서술형을 섞는다. **수능형 조판이 기본**이며 기출 내용·기관 로고·공식 시험 명칭·배점을 복제하지 않는다.
- A4 세로, 명확한 과목명/영역 제목, 단원 부제목, 이름·번호 빈칸, 큰 문항 번호. 중·고등과 초등 고학년의 짧은 문항은 중앙 구분선이 있는 2단, 단 사이 8~10mm.
- 읽는 순서는 왼쪽 위→아래, 오른쪽 위→아래로 고정한다. 단 사이에서 문항을 쪼개지 않는다. 저학년·긴 지문·큰 그림에는 1단 또는 별도 쪽을 쓴다.
- 명조 본문 11~12pt, 줄 간격 1.55~1.75. 수식은 별도 명조/수학 글꼴로 구분하고, 지수·괄호·곱셈기호·식 한 덩어리가 잘리지 않게 한다.
- 단답형보다 계산·서술형에 더 많은 답란을 준다. 답안선은 실제 border로 그리고, 반복 배경 그라디언트에만 의존하지 않는다.
- 5문항은 1쪽을 목표로 하되 가독성·풀이 공간이 부족하면 쪽을 늘린다. 배점·총점·등급·서열은 없다.

### B. `퀴즈_정답해설.pdf`

- 정답 요약 → 문항별 정답 → 풀이 → 예상 오개념 → 되묻기 발문 순서. 상자·배경·제목 위계로 각 부분을 구별한다.
- 오답 보기별 예상 오개념의 보기 번호와 내용을 재확인한다. 계산은 검산한다.
- 풀이 단계를 줄바꿈해 보이고, 정답 표시와 교사용 발문을 분리한다. 5문항이면 2쪽도 허용하며 작은 글씨로 1쪽에 압축하지 않는다.
- 마지막에는 점수 대신 "개념 구별 / 끝까지 해결 / 검산·근거 확인"처럼 재도전할 지점을 안내한다. 교과에 맞춰 표현을 바꾼다.

두 파일 모두 매 쪽 하단에 초안 문구·쪽수를 넣고 전체 쪽을 PNG로 시각 검수한다. 본문 아래와 하단 영역 사이에 최소 2mm 정도의 여유를 남긴다.

## 4. 수업용 AI 프롬프트

예시 틀(단원에 맞게 채운다):

```text
[Gemini Gems — 학생 연습 도우미 지침]
너는 <학년> <과목> '<단원>' 학습을 돕는 도우미야. 정답을 바로 알려 주지 말고, 한 단계씩 질문으로 힌트를 줘. 성취기준 <코드> 범위 안에서만 문제를 내. 학생에게 이름·학교 같은 개인정보를 묻지 마. 틀리면 왜 그렇게 생각했는지 먼저 물어봐.

[NotebookLM — 교사용]
(소스: 교육과정 원문 해당 쪽, 직접 만든 활동지·퀴즈) "이 소스를 바탕으로 <단원>에서 학생들이 자주 보이는 오개념 5가지와 각각을 바로잡는 발문을 정리해 줘. 소스에 없는 내용은 '소스에 없음'이라고 표시해 줘."
```

공통 안내: "학생 실명·성적 등 개인정보는 넣지 마세요."

코딩 에이전트는 이 전문을 `AI_프롬프트.txt`로 저장한다.
